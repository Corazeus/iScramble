# 🧩 iScramble

**iScramble** is a fast-paced word guessing game where players compete to decode scrambled words within a limited time. Originally built as a simple word puzzle game, it has now been enhanced with a **multiplayer mode**, making it more competitive, interactive, and engaging for group play.

---

## 🎮 Game Concept

In iScramble, players are presented with a scrambled version of a word. The goal is simple:

> Unscramble the word before your opponents do.

The faster and more accurate you are, the higher your score.

---

## 🌐 Multiplayer Upgrade

The latest version of iScramble introduces **real-time multiplayer functionality**, allowing players to:

- Compete with friends or teammates online
- Join shared game rooms
- Race to solve scrambled words first
- Track live scores and rankings
- Play structured rounds with a point system

This turns the game from a solo brain teaser into a **competitive party or team-based challenge**.
